O que o aluno deve fazer

Parte 1 - Entrega do Código (Peso 3)
O aluno deverá desenvolver um sistema CRUD completo, aplicando obrigatoriamente as seguintes operações:
#	Operação	O que fazer
1	INSERT (Create)	Cadastrar novos registros via formulário POST
2	SELECT (Read)	Listar e filtrar registros com WHERE ... LIKE '%termo%'
3	UPDATE (Update)	Editar registros com formulário pré-preenchido
4	DELETE (Delete)	Excluir registros via POST com confirmação

Requisitos técnicos obrigatórios
#	Requisito	O que fazer
1	Conexão OO	Usar new mysqli() orientado a objetos
2	connect_errno	Tratar falhas de conexão
3	Prepared Statements	Usar prepare() + bind_param() em TODAS as operações
4	htmlspecialchars()	Aplicar em TODAS as saídas (proteção XSS)
5	Exclusão via POST	Nunca usar GET para exclusão
6	Confirmação	Usar confirm() antes de excluir
7	Formulário semântico	Usar label for="" + name
8	Tratamento de ID inexistente	Exibir mensagem "Registro não encontrado"
9	Feedback ao usuário	Exibir mensagens de sucesso/erro
10	README.md	Documentar o projeto
Estrutura mínima esperada
projeto/
├── conexao.php      → Conexão com banco (mysqli OO)
├── index.php        → Listagem + busca
├── cadastrar.php    → INSERT
├── editar.php       → Carregar dados para edição
├── atualizar.php    → UPDATE
├── excluir.php      → DELETE
├── banco.sql        → Script de criação do banco
└── README.md        → Documentação

Material de Apoio

Para os alunos
Roteiro de estudos:
INSERT: INSERT INTO tabela (campo1, campo2) VALUES (?, ?)
SELECT: SELECT * FROM tabela WHERE campo LIKE ?
UPDATE: UPDATE tabela SET campo1 = ?, campo2 = ? WHERE id = ?
DELETE: DELETE FROM tabela WHERE id = ?
Prepared Statements: prepare(), bind_param(), execute()
htmlspecialchars() com ENT_QUOTES e UTF-8
Diferença entre GET e POST
confirm() em JavaScript
Exercícios sugeridos:
Criar um CRUD completo do zero
Reescrever a exclusão para POST
Adicionar htmlspecialchars() em todas as saídas
Implementar verificação de affected_rows
Criar README.md
Links úteis:
Documentação PHP: https://www.php.net/manual/pt_BR/
MDN Web Docs: https://developer.mozilla.org/pt-BR/
W3Schools MySQL: https://www.w3schools.com/php/php_mysql_intro.asp
